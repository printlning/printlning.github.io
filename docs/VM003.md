## 설정
![](../images/VM003/set01.png)
![](../images/VM003/set02.png)test를 선택하지 말고 목록에 없습니까?로 가서 아까 설정한 비밀번호를 입력하고 root로 로그인합니다.

<br/>
<br/>
<br/>

![](../images/VM003/set04.png)
![](../images/VM003/set05.png)
설정으로 가서 개인정보>화면 잠금의 빈 화면 지연 시간을 안 함으로 바꿨습니다.

<br/>
<br/>
<br/>

![](../images/VM003/set06.png)
```shell
systemctl stop firewalld
systemctl disable firewalld
grubby --update-kernel ALL -args selinux=0
```
방화벽과 selinux를 비활성화합니다.

<br/>
<br/>
<br/>

## IP 고정
![](../images/VM003/set07.png)
IP 고정을 위해서는 ens33.nmconnection 파일을 수정해야 합니다. ens33이 아니라 ens160일 수도 있습니다.

<br/>
<br/>
<br/>

![](../images/VM003/set08.png)
사진처럼 address1과 dns를 추가합니다. 서브넷 주소를 맞춰서 각자 원하는 IP를 address1에 적어주세요. 저는 50으로 했습니다. 서브넷 주소는 vmware 상단 메뉴의 Edit > Virtual Network Editor 에서 확인할 수 있어요. (어떻게 확인하는지 모르겠다면 [Kali Linux 설치](https://printlning.github.io/docs/VM001.html)의 IP 고정 부분을 참고하세요.)

<br/>
<br/>
<br/>

![](../images/VM003/set09.png)
![](../images/VM003/set10.png)
NetworkManager를 재시작하고 IP를 확인합니다.

<br/>
<br/>
<br/>

![](../images/VM003/set11.png)
ping도 잘 돌아가는지 확인합니다.

<br/>
<br/>
